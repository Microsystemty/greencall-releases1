# GreenCall para Windows

Instaladores e arquivos de atualização do GreenCall. O código-fonte permanece privado.

[Baixar a versão mais recente](https://github.com/Microsystemty/greencall-releases1/releases/latest)

A versão com atualizador automático precisa ser instalada manualmente uma vez. Depois, versões novas são baixadas em segundo plano e o aplicativo oferece Reiniciar para atualizar. Reiniciar encerra chamadas em andamento.

O instalador ainda não possui certificado de assinatura digital. O Windows pode mostrar aviso de editor desconhecido.
